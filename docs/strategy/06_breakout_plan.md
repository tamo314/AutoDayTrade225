# R002: Opening range breakout（事前登録）

登録日: 2026-09-13、R001終了後・この戦略の初回PnL計算前。R001はDevelopment上の初動方向のみではコストを回収できず2仮説とも棄却された。この知見に基づく次の探索であり、独立した未使用Development標本ではない。OOS/Final Holdoutはまだ使用していない。

## Hypothesis

初動の高値・安値で価格帯が形成された後、それを終値が突破する状態は、新たな注文フローが継続する候補局面かもしれない。終値での範囲突破が継続するかを検証する。R001の良い月や方向を選んで追加フィルターにしない。

## Implementation / Parameters tested

セッション開始からL分の連続した適格バーで高値の最大・安値の最小を固定。L本目までに発注しない。その後、終値が固定高値より大なら買い、固定安値より小なら売りのシグナルを出し、翌適格バー始値で約定する。等しいだけでは突破としない。初回のみ、1セッション1枚1取引。高安は突破バーを含めない。開場から120分未満に最初の突破がなければ見送る（固定した観測期限、最適化しない）。

L=[15,30,45]、H=[30,60,90]、代表点L30/H60。保有と退出はR001と同じ時間決済、Stop/Targetなし。Day/Nightの両方、Long/Shortの両方を評価し、後から好成績の部分だけを残さない。

## Development result / Validation result / Robustness result の事前基準

R001と同じ基準を採用する: 代表点の1/2 tick期待値>0、>=200取引、9点中6点以上が正、正の月>=50%、上位10利益除去後>0。12/3/3 Walk Forwardはtrainの9点中6点と代表点が正なら次窓に固定代表点を適用し、14窓中半数以上稼働・稼働窓過半数プラス・合算プラスを要求する。

0/1/2/3 tick、片道30円/60円、entry1分遅延、exit1分遅延、出口1分の不利価格overlay、seed225で1,000回の10%欠落・順序shuffle・bootstrapを実施。候補には2 tick、倍手数料、遅延、不利overlayでも期待値>0を要求。0 tickは選定に使わず、3 tickも診断を保存する。

必要条件を満たす場合だけ代表点仕様とDevelopment結果を凍結しOOSへ進む。OOS>=50取引、1/2 tick期待値>0、上位5利益除去後>0、遅延/倍手数料の耐性を要求する。2026年以降は開かない。

## Problems discovered / Decision / Next experiment

完全同一バーの重複はR001で文書化した方法を継続し、品質と約定監査を保存する。データ不足・計測問題はINVESTIGATE、事前の必要条件未達はREJECT。通過した場合のみCANDIDATEとし、メタ戦略の構築に進める根拠があるかを別に判断する。
